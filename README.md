# コード認識トレーニングアプリ

耳でコードを覚えるトレーニングアプリ。キー・コード種類の複数選択、再生後のアルペジオ、TTS読み上げに対応。

## 使い方

`ultimate-complete-app.html` をブラウザで開くか、ローカルサーバーで配信してください。

```bash
# 例: Pythonでローカルサーバー起動
python3 -m http.server 8000
# http://localhost:8000/ultimate-complete-app.html にアクセス
```

## 機能

- キー・コード種類の複数選択
- テーマ切り替え（ライト/ダーク）
- 再生後のアルペジオ
- TTS（コード名読み上げ）
- スマホ対応（viewport）
